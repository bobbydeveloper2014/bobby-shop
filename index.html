Bobby-Shop

Trang web bán hàng bằng PHP đơn giản
A simple PHP e-commerce web application

Cấu trúc thư mục / Directory Structure

bobby-shop/
├─ index.php
├─ config.php
├─ assets/
│  ├─ css/
│  ├─ js/
│  └─ images/
├─ includes/
├─ pages/
└─ README.html

Yêu cầu / Requirements

  • PHP >= 7.4
  • MySQL hoặc MariaDB (nếu dùng database / if using database)
  • Apache hoặc Nginx

Cách chạy trên Apache / How to run on Apache

  1. Copy toàn bộ folder bobby-shop vào thư mục htdocs hoặc www (ví dụ: C:/xampp/htdocs/bobby-shop)
    Copy all bobby-shop folder to htdocs or www folder (e.g., C:/xampp/htdocs/bobby-shop)
  2. Mở trình duyệt và truy cập: http://localhost/bobby-shop
    Open browser and visit: http://localhost/bobby-shop
  3. Nếu dùng database, chỉnh sửa file config.php với thông tin database.
    If using database, edit config.php with your database info.

Cách chạy trên Nginx / How to run on Nginx

  1. Copy toàn bộ folder bobby-shop vào thư mục web root của Nginx (ví dụ: /usr/share/nginx/html/bobby-shop)
    Copy all bobby-shop folder to Nginx web root (e.g., /usr/share/nginx/html/bobby-shop)
  2. Chỉnh sửa cấu hình server block Nginx:
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html/bobby-shop;
    index index.php index.html index.htm;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php7.4-fpm.sock;
    }
}
  1. Khởi động lại Nginx và PHP-FPM, sau đó truy cập http://localhost/bobby-shop
    Restart Nginx and PHP-FPM, then visit http://localhost/bobby-shop

Chú ý / Notes

  • Đảm bảo PHP và server đã được cài đặt và chạy bình thường.
  • Make sure PHP and the web server are installed and running properly.
